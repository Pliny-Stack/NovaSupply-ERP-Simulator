# NovaSupply ERP Simulator

## Overview

NovaSupply ERP Simulator is a configurable Python application that generates realistic enterprise supply chain datasets for Data Engineering, Microsoft Fabric, SQL, Power BI, and Machine Learning projects.

## Features

- Enterprise-scale ERP simulation
- Supply chain data generation
- Configurable dataset sizes
- Data quality issue injection
- CSV and Parquet export
- Documentation generation

## Tech Stack

- Python
- Pandas
- NumPy
- Faker
- Microsoft Fabric
- Power BI
